# 정보
## 푸는 절차
1. **조건 확인 + 복잡도 계산**: 조건을 빠짐없이 적고, 제약조건에서 목표 복잡도를 역산한다
2. **순서도 그리기 + 풀이 요약 작성**: 노트에 흐름을 그리고 (암산 금지), 주석으로 풀이를 먼저 쓴다
3. **반례 찾기**: 그리디·DP라면 착수 전에 반례부터 찾는다
4. **주석 아래 채우기**: 요약해둔 주석을 그대로 코드로 옮긴다
5. **엣지 케이스 넣어보기**: 최소·최대 입력을 넣고, 1번의 조건 목록과 대조한다

## 막혔을 때
1. 조건을 재확인한다 (혼자서만 더 어려운 제약을 두고 있진 않은지)
2. 접근법을 바꾼다 (같은 접근으로 3번 디버깅했으면 접근이 틀린 것)
3. 브루트포스라도 완성한다 (부분점수 확보 + 최적화의 출발점)
4. 1시간을 넘기면 답을 보고 배운다 → `review-notes.md`에 기록
